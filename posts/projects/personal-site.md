This is my personal website (the one you are currently browsing!) that showcases my projects, experiences, and technical interests.

## Key Features

- **Static Site Generation**: Built with a custom Python build script utilizing **Jinja2** for templating and **Mistune** for compiling Markdown project files.
- **Modern Styling**: Styled using **Tailwind CSS** with fully responsive layouts, clean grid designs, and a custom dark mode theme toggle.
- **Aesthetic Terminal theme**: Designed to mimic a retro-modern CLI terminal style, featuring custom fieldsets with mock commands like `cat` and `ls`.
- **Typing Game & Interactive Elements**: Features interactive elements like a typing speed test to keep visitors engaged.
